# Math's Jump & Go

A production-style mobile battery jump-start website and Cloud/DevOps portfolio project.

## Business purpose

Math's Jump & Go provides mobile battery jump-start assistance across Buckinghamshire and surrounding areas.

## Project goals

- Build a responsive business website and booking application
- Develop and test locally using WSL Ubuntu
- Use Git and GitHub with a professional branching workflow
- Automate testing and deployment using GitHub Actions
- Containerise the application with Docker
- Provision AWS infrastructure using Terraform
- Deploy with Kubernetes, Amazon EKS and Helm
- Implement GitOps, monitoring, logging and security
